# stick

아이디어와 온라인에서 발견한 영감 자료를 프로젝트별로 정리하는 정적 웹 앱입니다.

## 주요 기능

- 프로젝트 생성 및 삭제
- 프로젝트별 아이디어 작성과 태그 분류
- Instagram, YouTube, 일반 웹 주소의 제목, 설명, 대표 이미지 가져오기
- 영감 자료에 개인 메모와 태그 추가
- 전체 기록 검색 및 유형별 필터
- 브라우저 `localStorage`에 데이터 저장

## 실행

별도 빌드 없이 `index.html`을 열거나 정적 서버로 실행합니다.

```powershell
npx serve .
```

## URL 정보 가져오기

YouTube 링크는 브라우저 호출이 가능한 oEmbed 프록시를 통해 YouTube의 제목과 채널 정보를 가져오며 영상 ID로 대표 썸네일을 구성합니다. 그 외 URL 메타데이터는 브라우저에서 Microlink 공개 API를 호출해 가져옵니다. 플랫폼의 공개 범위, 로그인 요구 사항 또는 네트워크 상태에 따라 일부 Instagram 게시물 등의 정보는 자동으로 가져오지 못할 수 있습니다. 이 경우 제목과 메모를 직접 작성해 저장할 수 있습니다.

## 배포

Vercel에서 이 폴더를 프로젝트로 가져오면 별도 빌드 설정 없이 배포할 수 있습니다.

- Framework Preset: `Other`
- Build Command: 비워두기
- Output Directory: `.`
